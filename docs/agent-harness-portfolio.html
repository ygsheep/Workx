04关键工程能力

四项业界公认收益最大、且多数 harness 尚未完整覆盖的改动。

🔒
强制验证闭环
FinalAnswer 落地前执行验证判定，未通过则回灌失败原因重试，达上限后带警告降级终止。headless 与交互式均默认开启，验证目标按项目线索自适应探测。
对齐 LangChain PreCompletionChecklist
🧭
命令自适应探测
按项目线索推断可跑命令（CMake 须真生成过 CTest 入口 / Cargo / Go / npm script / Makefile / pytest）。探测不到返回 unavailable 并放行，不把「没得跑」误判为「跑了没过」。
避免为不存在的目标烧预算
🛡️
分层安全与权限
统一权限决策层 + 文件路径边界校验 + 命令白名单（字符串级拒绝分隔符注入）+ Windows Job Object 进程隔离。自动执行命令是硬性安全前置。
自动执行场景的 RCE 前置
💰
子 Agent 成本双护栏
SubAgentBudget 同时约束单批规模与 run 累计总量，atomic CAS 预约；成本爆炸风险从「无界」变为「可配上限」。
批量上限 + 全程总量
🕘
可审计 + 可回滚
git 基线检查点自动捕获，收尾输出改动清单；TUI /diff 与 /rollback --confirm 提供人工回滚入口。只读安全网，不自动回滚以免误删用户改动。
改动全程可追溯
📡
端到端可观测
结构化审计日志（JSONL / 脱敏 / 轮转）+ headless JSON 输出含 usage 统计 + 收尾 git diff 摘要，可直接对接评测 harness 采集。
无需改动输出协议即可采集
评分方法：LangChain《Improving Deep Agents with Harness Engineering》《The Anatomy of an Agent Harness》· Anthropic《Writing effective tools for agents》· HarnessTax（UC Berkeley × Arena）· Harbor（Terminal-Bench 官方 runner）
